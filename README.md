E-commerce completo desenvolvido em grupo (3 integrantes): catálogo de produtos, carrinho, checkout, área administrativa e autenticação com JWT via Spring Security. Frontend em Angular 19 com renderização no servidor (SSR) e backend em Java 17 com Spring Boot 3. Repositório documentado com referência de endpoints da API, esquema do banco de dados, fluxo de autenticação e tabela de rotas.

`Java 17` `Spring Boot 3` `Spring Security` `JWT` `Angular 19 (SSR)` `TypeScript` `SQLite`
